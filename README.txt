AMIRTHA VINUSHA PORTFOLIO
===========================

FILES
- index.html
- style.css
- script.js
- assets/   Add project images here
- fonts/    Add your licensed Brolimo/Brolimbo webfont here

RUN
Open index.html directly, or use a local server:
python3 -m http.server 8000

BROLIMO / BROLIMBO
The font itself is NOT included. If you own a licensed webfont:
1. Put the .woff2 file in fonts/
2. Open style.css
3. Uncomment the @font-face block at the top
4. Adjust the exact filename if needed

IMAGES
Every project starts with 3 editable visual slots.
Suggested names:
rapido-01.jpg, rapido-02.jpg, rapido-03.jpg
raack-01.jpg, raack-02.jpg, raack-03.jpg
krn-01.jpg, krn-02.jpg, krn-03.jpg
sundari-01.jpg, sundari-02.jpg, sundari-03.jpg
saregama-01.jpg, saregama-02.jpg, saregama-03.jpg

The "+ Add another image space" button demonstrates how additional slots look.
For permanent additional images, duplicate a .media-slot block in index.html.
