BRANDVERSE V6 — TRUE 3D CAMERA JOURNEY

Open index.html with an internet connection. Three.js loads from a CDN. Scroll controls a camera flying between 3D destination markers. Explore Map jumps to locations. Case studies open as separate overlays.

For GitHub Pages upload index.html, style.css, script.js and fonts/Brolimo.ttf to repository root.

Note: desktop GPU/browser performance varies. Reduced motion support is partial for camera transitions.
